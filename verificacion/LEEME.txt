verificacion/ — Pruebas automáticas usadas para comprobar la entrega
=====================================================================

IMPORTANTE: esta carpeta NO forma parte de la aplicación. La aplicación (ocr-local/ y
contexto-analisis/) funciona sin Node.js. Estas pruebas sí usan Node.js 18+ y Playwright, porque
hacía falta controlar un navegador real para obtener evidencias. Puede borrar la carpeta.

Cómo repetir las pruebas (opcional):
  1. Instale Node.js 18+ y Playwright (npx playwright install chromium) en un equipo de pruebas.
  2. Desde esta carpeta:
       node prueba-demo.js file:///RUTA/ocr-local/index.html imagenes/factura-es.png netlog.json captura.png
       python analizar-netlog.py netlog.json
       node prueba-casos.js
       node prueba-copias.js
       node prueba-contexto.js captura-contexto.png
       node prueba-fidelidad-y-sin-red.js
       node prueba-herramienta.js CARPETA_CON_LOS_4_TGZ_OFICIALES   (más bootstrap-manipulado.tgz,
            cualquiera.js y worker-suelto.min.js, como se describe en el propio script)
     Servidores: arránquelos en los puertos que prefiera y pase http://127.0.0.1:PUERTO/ a prueba-demo.js.
     Control del net-log: sirva ocr-local con servidor-local.py en el puerto 8831 y ejecute
       node control-netlog.js RUTA/control-netlog.html netlog-control.json
  3. Las sondas file:// (prueba-file-sondas.*, prueba-file-estandar.*) necesitan una carpeta vendor/
     junto a ellas con los archivos OFICIALES sin empaquetar (tesseract.min.js, worker.min.js,
     tesseract-core-simd-lstm.wasm.js, spa.traineddata.gz), una imagen factura-es.png y los
     envoltorios wrap-worker.js, wrap-core.js y wrap-spa.js (window.__SRC_WORKER, __SRC_CORE y
     __B64_SPA). Sirvieron para demostrar por qué la vía estándar no funciona en file://.
  4. empaquetar-referencia.py es el generador de referencia (Python) con el que se crearon los
     paquetes; la herramienta del navegador produce exactamente los mismos bytes (resultado 07).
  Variable opcional PLAYWRIGHT_MODULE: ruta del módulo playwright si no está en node_modules.
